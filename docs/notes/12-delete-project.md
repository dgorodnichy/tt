# Конспект к задаче 12. Сценарий «удалить проект»

Пополняется по ходу задачи: сюда записывается всё, что ты спросил и что мы выяснили.

## `expected declaration, found _` — код оказался вне функции

Лишняя `}` закрыла функцию раньше времени, и следующие строки оказались на верхнем уровне файла. Там Go разрешает только объявления: `func`, `type`, `var`, `const`, `import`. Действия (`x := ...`, `if`) — только внутри функции. Ищи `}` выше строки, на которую ругается компилятор.
