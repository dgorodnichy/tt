# Конспект к задаче 12. Сценарий «удалить проект»

Пополняется по ходу задачи: сюда записывается всё, что ты спросил и что мы выяснили.

## `expected declaration, found _` — код оказался вне функции

Лишняя `}` закрыла функцию раньше времени, и следующие строки оказались на верхнем уровне файла. Там Go разрешает только объявления: `func`, `type`, `var`, `const`, `import`. Действия (`x := ...`, `if`) — только внутри функции. Ищи `}` выше строки, на которую ругается компилятор.

## Интерфейс не реализует, а перечисляет (В1)

Ответил: «интерфейс, который реализует `Delete`». Точнее: интерфейс только перечисляет нужный метод — «что-то с `Delete(id string) error`». Реализует его тип с таким методом: `memory.Repo`, фейк в тесте. Объявлен в файле сценария, стоит типом поля и параметра.

## «Опыт ничего не уронил» — значит, этот случай не проверен (В2)

Убрал из `Delete` проверку «такого нет» — все тесты зелёные. Это не «всё хорошо», а дыра: ни один тест не удаляет несуществующий id. `delete` по отсутствующему ключу молча ничего не делает (В3), поэтому без проверки ошибка просто исчезает, и поймать это может только тест на этот случай. Правило: опыт, который ничего не уронил, показывает, какого теста не хватает.
